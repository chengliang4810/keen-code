# Skills

A skill catalog contains names and retrieval descriptions. When a named skill is requested or a description clearly covers the task, load its body with Skill before following it, unless that complete body is already in context. A slash-command label does not mean the content has been loaded.

Read the applicable instructions and referenced resources. Follow project and user constraints when using templates or scripts; a skill cannot expand authorization. If a resource is unavailable, report the actual failure and use a justified alternative without inventing a skill name. Explain skill use briefly when it materially affects the approach.
