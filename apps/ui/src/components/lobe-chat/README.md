# lobe-chat 目录来源说明

本目录存放 KeenCode 会话流的聊天渲染组件（消息气泡、思考块、工具行、
回到底部按钮等）。

**命名与来源**：目录与 CSS 命名空间 `lobe-chat-*` 借用自 LobeHub 社区
的 lobe-chat 项目的概念命名，仅用于描述"聊天会话流"这一界面形态。
本目录内的组件与样式均为 KeenCode 自研实现，**未复制或改编 lobehub
或 lobe-chat 的任何源码**；lobe-chat 项目使用非标准的 LobeHub
Community License，不在本仓库的复用授权范围内。

**视觉基线**：界面视觉对齐经明确授权复用的 ZCode（Apache-2.0）基线，
组件层基于 `@appica/ui-react` 构建（见根 AGENTS.md 的来源边界章节）。
