# Archived Design Research

本目录保存历史研究材料，不是 KeenCode 当前 UI 规范，也不作为 Design QA 的验收基线。

## 2026-09-19 Codex Desktop Design Analysis

`2026-09-19-codex-desktop-design-analysis.md` 是针对外部 Electron/Codex 桌面应用的只读反编译分析。它只用于记录当时的研究范围、观察和不确定性，不能证明 KeenCode 使用 Electron、外部产品的字体、变量、CSS 或组件实现。

当前产品的规范性来源是仓库内的 `DESIGN.md`、`src/styles/`、组件实现、测试和 `design-qa.md`。外部研究如被引用，必须先转化为与 KeenCode 宿主、组件来源、许可证和现有布局相容的独立决策。
