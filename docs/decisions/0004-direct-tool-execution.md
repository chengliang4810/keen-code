# ADR-0004：工具直接执行

- 状态：已采用
- 日期：2026-08-01

## 决策

KeenCode 加入项目时即获得该目录的工作范围。Agent 工具调用直接执行，运行时不定义
权限模式、信任记录、审批请求或逐次确认状态；`AskUserQuestion` 仅用于澄清任务，
不承担工具授权。

前端不显示信任步骤、权限弹窗或审批状态。后端不读取相关环境变量、配置字段或
历史记录，也不为未知审批请求增加兜底分支。

## 边界

- Read、Write、Edit、Glob、Grep 和 folder_operations 按当前路径规则解析：相对路径基于会话 `cwd`，绝对路径直接使用，已存在路径解析符号链接和 `..`，不存在路径规范化最近的已存在父目录；不额外限制项目根目录。Bash 从项目根目录启动宿主 Shell，不创建额外的文件系统沙箱，命令可按宿主系统权限访问其他路径。
- 子 Agent 继承父 Session 的项目根，模型不能覆盖工作目录。
- 每次文件修改、命令执行和网络工具调用都保留可审查记录。
- 操作系统权限、路径校验和工具参数校验仍然有效。

## 风险

用户无法在每次工具执行前阻止操作。模型可以在项目边界内修改或删除文件、执行
命令、访问网络并操作 Git 工作区。若将来需要人工审核，必须作为新的产品能力重新
设计，不能恢复已删除的状态或界面。
