# ADR-0001：保持工作台源码基线

- 状态：已采用
- 日期：2026-07-27

## 背景

KeenCode 已经拥有完整的桌面工作台组件、DOM 结构、样式、设计令牌和公共资源。界面迭代需要以仓库中的实际源码为准，避免根据截图重新生成近似实现造成长期漂移。

## 决策

1. 当前 `src/` 与 `public/` 是唯一界面源码基线。
2. 修改现有交互时优先复用当前组件、DOM、CSS、设计令牌和资源。
3. 不根据截图重写整个工作台；截图仅用于验证有意变更。
4. 品牌或产品语义变化必须保持既有盒模型和布局，除非需求明确要求重新设计。
5. 每次影响界面的修改都使用相同视口进行渲染检查，并记录有意差异。

## 后续边界

桌面界面只负责交互与状态投影。会话执行、系统能力和模型服务保持独立边界，不把具体供应商协议扩散到界面组件。
