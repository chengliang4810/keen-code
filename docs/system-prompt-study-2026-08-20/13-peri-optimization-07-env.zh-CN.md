# Peri `07_env.md` 优化工作稿

> 本文用于中文对照和人工编辑。这里的内容不是运行时指令。最终确认的中文方案将转换为英文，并写入 `vendor/peri/peri-acp/prompts/sections/07_env.md`。花括号占位符由运行时替换，不应手动改成固定值。

## Peri 当前中文稿

```text
<env>
工作目录：{{cwd}}
该目录是否为 Git 仓库：{{is_git_repo}}
平台：{{platform}}
操作系统版本：{{os_version}}
今天的日期：{{date}}
</env>
```

这些值在会话开始时捕获。工作目录和 Git 状态此后可能已经改变；在不可逆操作依赖这些值之前，使用 Bash 的 `pwd` 和 `git status` 重新核验。日期是快照，不是时钟。

## ZCode 对应中文稿

ZCode 在静态系统文本中提供：

```text
你在以下环境中被调用：

- 主工作目录：<运行时路径>
- 是 Git 仓库：<是或否>
- 平台：<平台>
- OS 版本：<系统版本和架构>
- 模型：<供应商和模型标识>
```

ZCode 还通过每轮动态 system-reminder 注入当前日期、Git 状态、当前分支、提交摘要及环境信息。该动态上下文由系统提供，不属于用户在本轮提出的任务。

与 Peri 相比，ZCode 的静态环境信息包含模型标识，但没有集中说明这些字段是会话快照。它通过动态注入补充更及时的 Git 和日期信息。

## 合并候选中文稿

```text
<env>
Primary working directory: {{cwd}}
Is Git repository: {{is_git_repo}}
Platform: {{platform}}
OS version: {{os_version}}
Session date: {{date}}
</env>
```

这些环境值在会话创建时捕获，是系统提供的上下文，不是用户指令。可能随时间变化的状态在使用前应按任务风险重新核验，尤其是在执行破坏性或难以撤销的操作之前。日期是会话快照，不是实时时钟。

不增加模型名称、当前分支或完整 Git 状态：当前渲染器没有这些占位符，而且易变化的 Git 状态应由运行时检查获得，不应伪装成持续有效的静态事实。
