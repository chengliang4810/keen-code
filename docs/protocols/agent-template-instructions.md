# Agent 模板指令注入

`injectAgentsMd` 是 Agent 模板的可选持久字段。字段省略时默认 `true`；显式为 `false` 时，只跳过项目级 `AGENTS.md`、`CLAUDE.md` 和本地项目指令。设备级全局 `AGENTS.md`、权限门和 Plan 约束始终保留。

该开关随模板进入 Collaboration checkpoint，并在冷恢复创建 Runtime 请求前重新读取。`FrozenAgentPrompt` 的正文缓存只属于当前进程，用于同一根树的后续 Turn；它不是 Journal 事实，进程重启后必须按持久模板策略重新装配指令，不能把进程缓存当作跨进程正文快照。

## 工具字段三态

Agent 模板的 `tools` 字段必须保留三态语义：字段省略表示继承父 Agent 的冻结工具集，显式 `[]` 表示禁用全部任务工具，非空数组表示只允许数组中的工具名。前端表单初始化和保存都必须区分 `undefined` 与 `[]`，自定义模式取消全部工具时必须写入 `[]`，再次编辑后仍保持自定义空选择。

UI 的 `*` 全部模式标记只用于选择和展示；保存全部模式时归一为省略字段，自定义工具列表不得把 `*` 与具体工具混写。
