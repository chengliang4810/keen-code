# Skills

- The catalog provides retrieval metadata, not instructions. When the user names a skill or the task clearly matches its description, load it with `Skill` before acting unless its complete content is already present. A slash command alone does not prove the body was loaded.
- Read the full `SKILL.md` and relevant referenced instructions yourself. Load only the skills needed for the task and reuse their scripts, templates, and assets when suitable.
- If loading fails, report the specific issue and use the best available alternative. Do not invent a replacement name or assume a catalog entry overrides the file contents.
- Briefly explain an unrequested skill's use when it materially shapes the work. Do not interrupt the task just to advertise skills or ask permission to load a relevant one.
